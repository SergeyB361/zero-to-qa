# Test Data Engineering, День 7 — Мини-проект: Test data generation

## Что это за день

Это мини-проект про системную работу с тестовыми данными, а не про одну конкретную технику.

Здесь важно соединить:
- factories;
- builder pattern;
- reusable datasets;
- edge cases;
- свойства и инварианты там, где это уместно.

## Что здесь проверяется

Мини-проект проверяет, умеешь ли ты:
- проектировать удобный слой тестовых данных;
- отделять defaults от вариаций;
- строить edge и invalid cases осознанно;
- делать набор данных пригодным для расширения и ревью.

## Как правильно проходить

1. Сначала прочитай `spec.md`.
2. Определи основные сущности и типы данных.
3. Затем реши, где достаточно factory, а где нужен builder.
4. После этого добавь reusable наборы и проблемные edge cases.

## Что считается хорошим результатом

По сильному решению видно:
- откуда берутся валидные defaults;
- как создаются вариации без шума;
- как покрываются edge и invalid cases;
- что test data layer можно поддерживать, а не переписывать при каждом изменении схемы.

## На что обратить внимание

- не превращай всё в один giant data helper;
- не создавай datasets без явного назначения;
- не путай случайность с качеством тестовых данных;
- следи, чтобы data layer улучшал читаемость тестов, а не прятал смысл.
