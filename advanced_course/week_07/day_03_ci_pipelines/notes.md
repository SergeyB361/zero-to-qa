# Infrastructure for QA, День 3 — CI pipelines

## Когда это нужно

Пока тесты живут только локально, они помогают одному человеку. CI pipeline превращает их в инженерный процесс, который работает одинаково для всей команды.

Pipeline нужен, чтобы:
- запускать проверки автоматически;
- собирать артефакты и отчёты;
- стабильно воспроизводить проверки на каждом изменении.

## Как об этом думать

Хороший mental model: pipeline — это сценарий доставки сигнала о качестве.

Он должен отвечать на вопросы:
1. что запускается на каждый `push`;
2. что считается обязательным gate;
3. какие материалы остаются после падения;
4. сколько стоит прогон по времени и ресурсам.

Pipeline — не “команда в YAML”, а инженерный контракт команды с качеством.

## Из чего обычно состоит pipeline

Типовой QA-pipeline делится на этапы:
- подготовка среды;
- установка зависимостей;
- быстрые проверки;
- более дорогие тесты;
- сбор отчётов и артефактов.

Не все типы тестов должны запускаться одинаково часто. Часто есть разбиение на:
- `smoke`;
- `PR checks`;
- nightly/regression;
- post-deploy проверки.

## Что делает pipeline хорошим

Хороший pipeline:
- предсказуем по шагам;
- не прячет всю логику в один giant step;
- сохраняет полезные артефакты;
- отражает реальный риск, а не просто “запускает всё подряд”.

## Где ошибаются чаще всего

- один огромный шаг на весь процесс;
- нет разделения между быстрыми и дорогими тестами;
- падение есть, а материалов для расследования нет;
- pipeline копирует локальный хаос вместо того, чтобы наводить порядок;
- нет ясного ответа, какой набор проверок обязателен для merge.

## Что важно перед практикой

Перед `practice.py` ты должен понимать:
1. зачем вообще нужен CI для QA-проекта;
2. как делить pipeline на осмысленные этапы;
3. почему smoke, regression и артефакты — это разные задачи внутри одного процесса.

1. Открой `examples.py` и посмотри на структуру типового QA-pipeline.
2. Затем переходи к `practice.py`.
3. В каждом задании сначала формулируй цель pipeline: быстрый сигнал, полная проверка или расследуемый прогон.
