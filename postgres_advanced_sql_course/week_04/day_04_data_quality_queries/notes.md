# Data quality queries

## Когда это нужно
Даже хороший report бесполезен, если входные данные грязные.

## Как об этом думать
Quality query — это проверка конкретного правила качества:
- пропуски;
- дубли;
- нелогичные комбинации полей;
- orphan-строки и другие признаки поломанного dataset.

## Что нужно понимать перед практикой
1. quality query всегда проверяет правило;
2. данные могут быть формально валидны по схеме, но плохи по бизнес-смыслу;
3. quality checks — часть engineering workflow.
