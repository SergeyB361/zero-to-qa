# Capstone: SQL investigation pack

## Зачем нужен этот день
Это финальная сборка продвинутого Postgres SQL-трека: набор advanced-запросов, который помогает инженеру или QA быстро разобраться в состоянии системы.

## Что считается сильным результатом
Сильный capstone — это 4-6 понятных investigation blocks, логичный demo flow и использование advanced Postgres-инструментов по делу.
