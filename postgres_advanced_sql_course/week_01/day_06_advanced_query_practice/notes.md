# Практика на advanced querying

## Зачем нужен этот день
Первые пять дней недели дали отдельные инструменты:
- обычные CTE;
- recursive CTE;
- window functions;
- ranking;
- `LEAD` / `LAG` / running totals.

Финальная практика недели нужна, чтобы собирать их в цельные аналитические запросы.

## Что считается хорошим решением
Хороший advanced SQL-запрос:
- разбит на смысловые шаги;
- использует window functions там, где они действительно нужны;
- не делает лишние self-join'ы, если то же самое решается окном;
- читается как аналитический pipeline, а не как набор случайных кусков.

## Как подходить к задаче
1. Понять, нужен ли тебе подготовительный слой через CTE.
2. Понять, нужен ли глобальный контекст на каждой строке через window.
3. Если нужно выбрать top-строку на группу, думать про ranking.
4. Если нужен временной ряд, думать про recursion или календарь.

## Что особенно важно
- не использовать recursion только ради recursion;
- явно контролировать сортировку внутри окон;
- не терять читаемость, если запрос состоит из нескольких CTE подряд.

## Что должно получиться
После этого дня ты должен уметь читать и писать маленькие аналитические запросы уровня "не просто GROUP BY", а уже с промежуточными слоями и оконной логикой.
