# Capstone: Advanced SQL Report

## Что это за день

Это финальный capstone по advanced SQL.

Здесь нужно показать не знание отдельных операторов, а способность собрать серьёзное SQL-решение из нескольких техник сразу.

## Что здесь проверяется

Capstone проверяет, умеешь ли ты:

- декомпозировать аналитическую задачу;
- использовать `CTE`, оконные функции и агрегаты осознанно;
- думать о читаемости итогового SQL;
- замечать возможные проблемы performance и качества данных;
- оформлять результат как инженерный артефакт, а не как набор случайных запросов.

## Как правильно проходить

1. Сначала внимательно прочитай `spec.md`.
2. Определи, какой итоговый артефакт нужен: отчёт, витрина, investigation pack.
3. Разбей решение на этапы: подготовка данных, вычисление метрик, итоговая форма результата.
4. Только потом собирай финальный SQL.

## Что считается сильным решением

Хорошее capstone-решение:

- читается по шагам;
- использует сложные конструкции там, где они действительно нужны;
- даёт понятный итоговый результат;
- может быть объяснено другому инженеру без длинных устных комментариев.

## На что обратить внимание

- не делай один гигантский запрос без структуры;
- не усложняй SQL ради сложности;
- проверяй промежуточные шаги отдельно;
- следи за названием `CTE`, колонок и выходных метрик.
