# Capstone: SQL Investigation Pack

## Цель
Собрать итоговый пакет SQL-расследований: производительность endpoint, failed runs по релизам, дефекты и data-quality checks.

## Что должно получиться
- `slow_endpoints`
- `failed_runs_by_release`
- `critical_defects`
- `data_quality_summary`
- `итоговый SQL-скрипт` с итоговым investigation report

## Как подходить к проекту
1. Запусти starter SQL-скрипт и посмотри expected demo flow.
2. Напиши запросы по одному.
3. Проверяй, что SQL остаётся читаемым.
4. В конце оформи читаемый итоговый SQL-скрипт.
