# Индексы: база

## Зачем это нужно
Индекс нужен не “на всякий случай”, а для ускорения конкретных шаблонов поиска. Понимание этого критично для зрелого SQL-мышления.

## Ключевые идеи
- индекс как вспомогательная структура
- поиск по равенству и диапазону
- trade-off запись/чтение

## Практический фокус
Сначала пойми, какие поля часто используются в WHERE, JOIN и ORDER BY. Только потом думай про индекс.

## Типичные ошибки
- создавать индексы на всё подряд
- игнорировать стоимость обновлений
- не смотреть план запроса

## Практика
В `practice.sql` реализуй функции:
- `create_runs_status_index` - Создай индекс на `test_runs(status)` и верни True, если индекс появился.
- `list_indexes_for_runs` - Верни список индексов таблицы test_runs.
- `query_plan_for_failed_runs` - Верни план запроса по status = failed после создания индекса.

## Что дальше
Сначала запусти `examples.sql`, затем доведи функции из `practice.sql` до expected-результатов.
