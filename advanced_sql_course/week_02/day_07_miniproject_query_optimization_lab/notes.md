# Мини-проект: Query Optimization Lab

## Цель
Собрать набор простых performance-исследований: план до индекса, план после индекса, и небольшие rewrite-примеры.

## Что должно получиться
- `plan_for_failed_runs`
- `plan_for_orders_endpoint`
- `add_indexes`
- `slow_endpoints`
- `итоговый SQL-скрипт` с выводом before/after

## Как подходить к проекту
1. Запусти starter SQL-скрипт и посмотри expected demo flow.
2. Напиши запросы по одному.
3. Проверяй, что SQL остаётся читаемым.
4. В конце оформи читаемый итоговый SQL-скрипт.
