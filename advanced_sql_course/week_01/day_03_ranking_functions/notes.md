# Ranking functions

## Когда это нужно
Ranking functions нужны, когда строки надо не просто отсортировать, а присвоить им место внутри группы.

Типичные задачи:
- найти топ-3 самых медленных кейса;
- определить место инженера по числу failed run;
- ранжировать endpoint'ы по latency внутри сервиса.

## Какие функции здесь главные
Базовые ranking functions:
- `ROW_NUMBER()`
- `RANK()`
- `DENSE_RANK()`

Они похожи, но ведут себя по-разному при одинаковых значениях.

## Как об этом думать
Сначала задаёшь себе 2 вопроса:
1. Внутри какой группы я ранжирую строки?
2. Что делать с одинаковыми значениями?

Если значения одинаковые:
- `ROW_NUMBER()` всё равно раздаст уникальные номера;
- `RANK()` даст одинаковый ранг, но оставит “дырку” после ничьей;
- `DENSE_RANK()` даст одинаковый ранг без дырки.

## Базовый синтаксис
```sql
SELECT
    case_id,
    duration_sec,
    RANK() OVER (ORDER BY duration_sec DESC) AS duration_rank
FROM test_runs;
```

Это читается так:
- отсортируй строки по `duration_sec` от большего к меньшему;
- присвой каждой строке ранг по этой сортировке.

## Когда использовать каждую функцию
### ROW_NUMBER()
Подходит, когда нужен строго уникальный порядковый номер.

### RANK()
Подходит, когда равные значения должны делить одно место, и после ничьей допустим пропуск следующего номера.

### DENSE_RANK()
Подходит, когда равные значения делят одно место, но нумерация должна оставаться плотной.

## Практический смысл
Ranking functions нужны для:
- top-N задач;
- списков лидеров/антилидеров;
- аналитики по производительности;
- выбора “лучшей” или “худшей” строки внутри группы.

## Частые ошибки
- не задавать явный `ORDER BY` в окне;
- брать `ROW_NUMBER()`, хотя по смыслу нужен `RANK()`;
- не понимать поведение при ничьей;
- забывать `PARTITION BY`, если ranking должен быть по группам, а не по всей таблице.

## Что важно перед практикой
1. Понимать разницу `ROW_NUMBER` / `RANK` / `DENSE_RANK`.
2. Ясно определять группу ранжирования.
3. Ясно определять поле сортировки.
4. Понимать, как выбирать top-N из уже ранжированных строк.
