# Мини-проект: аналитические SQL-запросы

## Цель
Собрать набор аналитических запросов поверх test_runs, defects и api_checks с использованием CTE и оконных функций.

## Что должно получиться
- `slowest_cases`
- `failed_runs_by_release`
- `api_latency_ranking`
- `defect_summary`
- `итоговый SQL-скрипт` с отчётом

## Как подходить к проекту
1. Запусти starter SQL-скрипт и посмотри expected demo flow.
2. Напиши запросы по одному.
3. Проверяй, что SQL остаётся читаемым.
4. В конце оформи читаемый итоговый SQL-скрипт.
