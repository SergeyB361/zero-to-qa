# LEAD, LAG, running totals

## Зачем это нужно
Эти функции полезны для анализа последовательностей: что было до, что будет после и как накапливается метрика во времени.

## Ключевые идеи
- LEAD
- LAG
- running total
- анализ временного ряда

## Практический фокус
Хорошо подходит для релизной аналитики, трендов по дефектам и накопления объёма прогонов по дням.

## Типичные ошибки
- не сортировать по времени
- сравнивать соседние строки без понятного ORDER BY

## Практика
В `practice.py` реализуй функции:
- `lag_release_dates` - Верни пары `build_tag:prev_date`.
- `running_failed_runs` - Верни пары `run_id:cumulative_failed` по времени.
- `lead_api_checks` - Верни пары `check_id:next_status_code`.

## Что дальше
Сначала запусти `examples.py`, затем доведи функции из `practice.py` до expected-результатов.
