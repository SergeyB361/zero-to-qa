# Курс: SQL — продвинутый уровень

Продвинутый курс по аналитическим запросам, производительности, транзакциям и SQL в реальных системах.

## Зачем нужен курс
- перейти от базовых SELECT/JOIN к зрелому SQL-мышлению;
- понимать, как читать и оптимизировать тяжёлые запросы;
- разбираться в транзакциях, изоляции и integrity;
- использовать SQL как инженерный инструмент в QA, backend и аналитике.

## Формат
- `4` недели
- `7` дней в неделе
- обычный день: `notes.md`, `examples.py`, `practice.py`
- день мини-проекта: `notes.md`, `spec.md`, основной `.py` файл

## Структура курса
- `week_01/` — Advanced querying
- `week_02/` — Optimization and indexing
- `week_03/` — Transactions and consistency
- `week_04/` — SQL in real systems
