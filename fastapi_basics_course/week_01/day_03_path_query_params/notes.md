# FastAPI Basics, Week 1 Day 3 — path и query parameters

## Где это нужно в реальном API
Почти любой API принимает данные не только в request body, но и прямо в URL.

Обычно это два разных типа входных данных:
- path params;
- query params.

Очень важно не смешивать их роли.

## Как различать path и query
### Path params
Path params обычно идентифицируют конкретный ресурс.

Пример:
```text
/users/42
```

Здесь `42` — это часть пути. Без неё detail route не имеет смысла.

### Query params
Query params обычно уточняют выборку.

Пример:
```text
/users?team=api&limit=10
```

Здесь:
- `team=api` — фильтр;
- `limit=10` — ограничение размера ответа.

То есть query params обычно не говорят “какой именно это ресурс”, а говорят “как именно выбрать или показать данные”.

## Как это выглядит в FastAPI
```python
@app.get('/users/{user_id}')
def get_user(user_id: int):
    ...

@app.get('/users')
def list_users(team: str | None = None, limit: int = 10):
    ...
```

Что важно:
- `user_id` FastAPI берёт из path;
- `team` и `limit` — из query string;
- типы объявляются прямо в сигнатуре функции.

## Почему типы здесь важны
FastAPI умеет сам преобразовывать входные значения.

Например:
- `'10'` может стать `int`;
- `'true'` может стать `bool`.

Это делает код удобнее, но не отменяет необходимости думать о валидности входных данных.

## Когда path обязателен, а query часто нет
Обычно:
- path params обязательны, потому что без них маршрут не определён;
- query params часто опциональны, потому что у фильтра, лимита или сортировки может быть default.

Это не абсолютный закон, но как базовая модель работает хорошо.

## Частая ошибка мышления
Плохой вопрос:
- “Можно ли вообще засунуть это значение в path?”

Хороший вопрос:
- “Это идентификатор ресурса или настройка выборки?”

Если это идентификатор — скорее path.
Если это фильтр, сортировка, limit, offset — скорее query.

## Где ошибаются чаще всего
- Путают фильтр и идентификатор.
- Делают query param обязательным без явной причины.
- Не думают, какие значения могут быть невалидными.
- Превращают URL в нечитаемую строку с десятком разнотипных параметров.

## Что нужно вынести из урока
Перед практикой ты должен понимать:
1. зачем нужны path params;
2. зачем нужны query params;
3. как FastAPI достаёт и типизирует их прямо через сигнатуру route-функции.
