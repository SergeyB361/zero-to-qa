# Backend/API analysis

## Зачем это нужно
Когда backend ведёт себя странно, команде нужен не “красивый SQL-отчёт”, а быстрый ответ на инженерный вопрос.

## Как об этом думать
SQL здесь работает как инструмент расследования:
- какие endpoint деградировали;
- где выросли ошибки;
- как это связано с релизом или дефектами.

## Что важно на практике
- отвечать на один вопрос одним запросом;
- выбирать понятную агрегацию;
- не смешивать несколько метрик в один тяжёлый отчёт.

## Что должно остаться после урока
После этого дня ты должен уметь переводить инженерный вопрос в короткий рабочий SQL-анализ.
