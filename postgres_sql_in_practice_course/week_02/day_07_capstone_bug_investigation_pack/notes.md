# Capstone: bug investigation pack

## Зачем нужен этот день
Это финальная сборка applied Postgres-трека: не отдельные helper-ы, а комплект инженерных артефактов для расследования бага.

## Что считается сильным результатом
Сильный capstone — это маленький, но цельный toolkit:
- гипотеза;
- focused queries;
- findings;
- итоговый вывод для команды.
