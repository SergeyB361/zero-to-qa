# Query logging и artifacts

## Зачем это нужно
Applied SQL полезен только тогда, когда результаты можно сохранить, показать команде и воспроизвести.

## Как об этом думать
Нужен не просто запрос, а след его выполнения:
- какой запрос запускался;
- когда;
- с какими параметрами;
- какой вывод был получен.

## Что важно на практике
- логировать SQL-артефакты аккуратно;
- не хранить секреты в логах;
- сохранять достаточно контекста для повторного запуска.
