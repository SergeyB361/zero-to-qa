# Python + psycopg basics

## Зачем это нужно
На applied-уровне SQL живёт не только в `.sql`-файлах, но и внутри Python-кода: DB checks, setup/cleanup, технические проверки, investigation scripts.

## Как об этом думать
`psycopg` — это bridge между Python и Postgres.

Тебе нужен понятный минимальный workflow:
1. открыть соединение;
2. выполнить запрос;
3. получить результат;
4. закрыть соединение.

## Что важно на практике
- подключаться через DSN/host/user/password;
- использовать context manager;
- не забывать commit там, где есть изменение данных;
- держать SQL читаемым даже внутри Python.

## Что должно остаться после урока
После этого дня ты должен уметь написать маленький Python-скрипт, который подключается к Postgres и возвращает результат запроса.
