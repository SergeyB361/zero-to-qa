# Мини-проект: DB Checks Toolkit

## Зачем нужен этот день
Нужен маленький, но реальный applied-артефакт: набор helper-функций для DB-check'ов поверх Postgres.

## Что считается сильным результатом
Сильный результат — это не “куча функций”, а компактный toolkit, который решает 3-4 типовые задачи и читается как инженерный utility.
