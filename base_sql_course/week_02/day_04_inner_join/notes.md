# INNER JOIN



## Когда это нужно

`INNER JOIN` нужен, когда данные лежат в разных таблицах, но логически относятся к одному объекту: задача и исполнитель, заказ и пользователь, запуск теста и тест-кейс.



## Как думать о `JOIN`

`JOIN` - это не магическое склеивание всего со всем. Это способ сказать базе: возьми строки из двух таблиц и сопоставь их по правилу связи.



Обычно правило связи выглядит так:

```sql

ON tasks.assignee_id = users.id

```

Это значит: строка из `tasks` должна соединиться с той строкой `users`, где `id` совпадает с `assignee_id`.



## Что делает именно `INNER JOIN`

`INNER JOIN` оставляет только те строки, для которых пара нашлась с обеих сторон.



Если у задачи нет подходящего пользователя, такая задача в результате не появится.



## Как читать результат

Запрос:

```sql

SELECT t.id, u.name

FROM tasks AS t

INNER JOIN users AS u ON t.assignee_id = u.id;

```

по смыслу делает так:

1. проходит по строкам `tasks`;

2. для каждой строки ищет подходящую строку `users`;

3. если совпадение найдено, строит объединённую строку результата;

4. если совпадения нет, строка отбрасывается.



## Почему `alias` почти обязательны

После `JOIN` имена таблиц быстро становятся длинными и шумными. Alias вроде `t` и `u` делают запрос читаемым.



Это не косметика. В сложных запросах без alias читать и поддерживать SQL тяжело.



## Где это нужно QA

Очень частые сценарии:

- получить название пользователя для задачи;

- посмотреть владельца проекта;

- связать `test_runs` и `test_cases`;

- проверить целостность данных между таблицами.



## Частые ошибки

- соединять таблицы не по тем колонкам;

- забывать условие `ON` и получать взрыв числа строк;

- не понимать, что `INNER JOIN` выбрасывает строки без пары;

- путаться в колонках с одинаковыми именами (`id`, `name`, `status`).



## Что проверить перед практикой

Перед `practice.sql` ты должен понимать:

1. по каким колонкам строится связь;

2. почему `INNER JOIN` не покажет строку без совпадения;

3. зачем alias нужны не только для красоты, но и для ясности.
