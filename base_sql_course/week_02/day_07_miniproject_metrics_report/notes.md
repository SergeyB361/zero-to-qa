# Мини-проект: отчёт с JOIN и агрегациями

## Что это за проект
Собрать маленький SQL-отчёт по тестовым запускам, используя JOIN, GROUP BY и агрегаты.

## Что должно получиться
- функция `runs_per_status(conn)`
- функция `avg_duration_per_case(conn)`
- функция `open_defects_by_severity(conn)`
- читаемый `main()` с выводом отчёта

## Как идти по проекту
1. Запусти starter-файл и посмотри expected demo flow.
2. Реализуй функции по одной.
3. После каждой функции сверь вывод `main()`.
4. В конце почисти код и названия.
