# GROUP BY



## Когда это нужно

`GROUP BY` нужен, когда итог надо получить не по всей выборке сразу, а по категориям: по статусу, по пользователю, по проекту, по дню.



## Как об этом думать

Без `GROUP BY` агрегат сворачивает весь набор строк в одно значение.

С `GROUP BY` база сначала делит строки на группы, а потом считает итог внутри каждой группы.



Например, запрос:

```sql

SELECT status, COUNT(*) FROM tasks GROUP BY status;

```

не считает одно общее количество задач. Он разбивает таблицу `tasks` на несколько корзин по `status`, а затем считает строки внутри каждой корзины.



## Что физически происходит по смыслу

Можно мысленно представить такой процесс:

1. берём все строки;

2. раскладываем их по группам, где одинаковый `status` лежит вместе;

3. для каждой группы считаем `COUNT(*)`;

4. возвращаем одну строку на каждую группу.



Поэтому после `GROUP BY` результат меняет форму: это уже не исходная таблица, а сводка.



## Почему нельзя свободно писать любые колонки

Если в запросе есть `GROUP BY`, то в `SELECT` можно безопасно выводить:

- колонки из `GROUP BY`;

- агрегатные выражения вроде `COUNT(*)`, `AVG(score)`.



Нельзя просто так вывести случайную колонку, которая не участвует ни в группировке, ни в агрегате. База не поймёт, какое именно значение брать из группы.



## Где это нужно QA

Типичные задачи:

- посчитать количество багов по severity;

- посмотреть число тестов по статусу;

- посчитать заказы по пользователям;

- получить сводку запусков по дням.



## Частые ошибки

- забывать, что `GROUP BY` меняет форму результата;

- пытаться вывести колонку, которая не агрегирована и не входит в группировку;

- не понимать, что `WHERE` фильтрует строки до группировки;

- не сортировать результат и потом путаться при чтении.



## Что проверить перед практикой

Перед `practice.sql` ты должен уметь объяснить:

1. что такое группа строк;

2. почему после `GROUP BY` одна группа превращается в одну строку результата;

3. почему `SELECT status, title, COUNT(*) ... GROUP BY status` обычно неверен.
