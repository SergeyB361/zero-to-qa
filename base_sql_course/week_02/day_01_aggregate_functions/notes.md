# Агрегатные функции

## Когда это нужно
Агрегатные функции отвечают на вопросы не про одну строку, а про выборку целиком: сколько записей найдено, какой минимальный приоритет, сколько всего багов, каков средний балл.

## Как об этом думать
Обычный `SELECT` читает строки по одной. Агрегатная функция сначала берёт набор строк, а потом сворачивает его в одно итоговое значение.

Например:
- `COUNT(*)` считает строки;
- `SUM(points)` складывает значения колонки;
- `AVG(duration)` считает среднее;
- `MIN(created_at)` и `MAX(created_at)` ищут границы.

То есть агрегатная функция не возвращает "ещё одну обычную строку". Она возвращает итог по набору данных.

## Почему `COUNT(*)` и `COUNT(column)` - не одно и то же
`COUNT(*)` считает все строки, которые попали в выборку.
`COUNT(column)` считает только те строки, где в этой колонке нет `NULL`.

Это важно. Если ты считаешь заполненные даты завершения задачи, то `COUNT(completed_at)` даст меньше строк, чем `COUNT(*)`, и это будет корректно.

## Как читать агрегатный запрос
Когда ты пишешь:
```sql
SELECT COUNT(*) AS total_tasks FROM tasks WHERE status = 'open';
```
база делает по смыслу так:
1. берёт таблицу `tasks`;
2. оставляет только строки со статусом `open`;
3. считает, сколько таких строк осталось;
4. возвращает одно число.

## Где это нужно QA
Агрегации постоянно встречаются в проверках данных:
- сколько заказов создалось после API-запроса;
- сколько записей попало в лог-таблицу;
- сколько тест-кейсов в статусе `failed`;
- есть ли вообще хотя бы одна строка после действия.

## Частые ошибки
- путать `COUNT(*)` и `COUNT(column)`;
- ожидать, что `AVG()` округлит число так, как удобно человеку;
- забывать фильтр `WHERE`, из-за чего считается вся таблица;
- не давать результату alias, из-за чего итоговая колонка читается плохо.

## Что проверить перед практикой
Перед `practice.py` ты должен понимать:
1. чем агрегатная функция отличается от обычного чтения колонок;
2. почему `COUNT(*)` и `COUNT(column)` могут дать разный результат;
3. как по смыслу выполняется запрос `SELECT COUNT(*) FROM tasks WHERE status = 'open'`.
