# COUNT, SUM, AVG, MIN, MAX

## Зачем это нужно
Агрегации нужны, когда тебе нужен не список строк, а итог: сколько запусков, какая средняя длительность и какой максимум по оценке.

## Что нужно понять
- COUNT
- SUM
- AVG
- MIN
- MAX
- агрегация по выборке

## Рабочая логика
1. Определи, из каких таблиц ты читаешь данные.
2. Сузь выборку фильтрами.
3. Только потом добавляй сортировку, группировку или join.
4. Проверяй вывод на маленьком наборе данных.

## Примеры
### Пример 1 - Количество test_runs
```sql
SELECT COUNT(*) AS run_count FROM test_runs;
```

### Пример 2 - Средняя длительность тест-рана
```sql
SELECT AVG(duration_sec) AS avg_duration FROM test_runs;
```

### Пример 3 - Максимальная оценка задачи
```sql
SELECT MAX(estimate_hours) AS max_estimate FROM tasks;
```

## Типичные ошибки
- путать `COUNT(*)` и `COUNT(column)`
- не фильтровать данные до агрегации
- забывать alias для читаемого результата

## Практика
В `practice.py` есть функции для самостоятельной реализации:

- `min_and_max_run_duration` - Верни кортеж из минимальной и максимальной длительности test_runs.
