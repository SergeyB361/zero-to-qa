# Курс: SQL — базовый уровень

Pure SQL-трек без Python- и QA-слоя внутри самих уроков.

## Зачем нужен курс
- собрать фундамент по SQL как по отдельному языку;
- научиться читать и писать запросы без опоры на Python-код;
- подготовиться к продвинутому SQL и отдельно к прикладному треку `sql_in_practice_course`.

## Формат
- `4` недели
- `7` дней в неделе
- обычный день: `notes.md`, `examples.py`, `practice.py`
- день мини-проекта: `notes.md`, `spec.md`, основной `.py` файл

## Структура курса
- `week_01/` — SELECT и фильтрация
- `week_02/` — Агрегации и JOINs
- `week_03/` — Подзапросы и схема данных
- `week_04/` — Чистый SQL: закрепление и composite queries

## Связанные файлы
- `ROADMAP.md` — полный план по неделям и дням
