# Курс: SQL — базовый уровень

Pure SQL-трек без Python- и QA-слоя внутри самих уроков.

## Зачем нужен курс
- собрать фундамент по SQL как по отдельному языку;
- научиться читать и писать запросы без опоры на Python-код;
- подготовиться к продвинутому SQL и отдельно к прикладному треку `sql_in_practice_course`.

## Формат
- `4` недели
- `7` дней в неделе
- обычный день: `notes.md`, `examples.sql`, `practice.sql`
- день мини-проекта: `notes.md`, `spec.md`, основной `.sql` файл

## Как выполнять SQL без Python
- рекомендуемый вариант на Windows: `DB Browser for SQLite`, `DBeaver` или `SQLiteStudio`;
- открой `.sql` файл целиком и выполняй его по секциям сверху вниз;
- сначала выполняй `examples.sql`, затем `practice.sql`;
- в мини-проектах выполняй основной `.sql`-скрипт после чтения `spec.md`;
- если установлен `sqlite3` CLI, можно запускать и через него, но курс на это не завязан.

## Структура курса
