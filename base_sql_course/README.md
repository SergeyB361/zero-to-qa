# Курс: SQL — базовый уровень

Базовый курс по SQL для QA, backend-логики и проверки данных.

## Зачем нужен курс
- научиться уверенно читать и писать SQL-запросы;
- понимать структуру таблиц, связи и простые схемы данных;
- использовать SQL для QA-проверок и анализа данных;
- подготовиться к продвинутому SQL-треку.

## Формат
- `4` недели
- `7` дней в неделе
- обычный день: `notes.md`, `examples.py`, `practice.py`
- день мини-проекта: `notes.md`, `spec.md`, основной `.py` файл

## Структура курса
- `week_01/` — SELECT и фильтрация
- `week_02/` — Агрегации и JOINs
- `week_03/` — Подзапросы и схема данных
- `week_04/` — SQL для QA и Python

## Связанные файлы
- `ROADMAP.md` — полный план по неделям и дням
