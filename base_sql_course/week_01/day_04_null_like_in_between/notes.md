# NULL, LIKE, IN, BETWEEN

## Когда это нужно
Эти конструкции нужны очень рано, потому что почти любая реальная фильтрация выходит за рамки простого `=`.

С их помощью ты можешь:
- искать отсутствующие значения;
- фильтровать строки по шаблону;
- проверять попадание в список значений;
- отбирать диапазон чисел, дат или длительностей.

## NULL: самая важная особенность
`NULL` означает не пустую строку и не ноль, а отсутствие значения.

Из-за этого с ним нельзя работать как с обычным значением через `=`.

Правильно:
```sql
WHERE closed_at IS NULL
```

Неправильно:
```sql
WHERE closed_at = NULL
```

Почему так: `NULL` в SQL не сравнивается как обычное значение. Для него нужны `IS NULL` и `IS NOT NULL`.

## LIKE: поиск по шаблону
`LIKE` используется, когда нужно искать строку не по полному совпадению, а по шаблону.

Пример:
```sql
WHERE title LIKE 'Create%'
```

Это значит: найти строки, где `title` начинается с `Create`.

Основные шаблоны:
- `%` — любое количество символов;
- `_` — ровно один символ.

Примеры:
```sql
WHERE name LIKE 'A%'
WHERE code LIKE 'A_1'
```

## IN: проверка по списку значений
`IN` нужен, когда допустимых значений несколько, и ты не хочешь писать длинную цепочку `OR`.

Пример:
```sql
WHERE status IN ('open', 'in_progress')
```

Это читается проще, чем:
```sql
WHERE status = 'open' OR status = 'in_progress'
```

## BETWEEN: диапазон значений
`BETWEEN` используется, когда нужно проверить, что значение попадает в диапазон.

Пример:
```sql
WHERE duration_sec BETWEEN 35 AND 60
```

Это значит: взять значения от `35` до `60` включительно.

Важно: `BETWEEN` включает обе границы.

## Как выбирать инструмент
Если задача звучит так:
- "значение отсутствует" -> `IS NULL`;
- "начинается с ..." или "похоже на ..." -> `LIKE`;
- "одно из нескольких значений" -> `IN`;
- "в диапазоне от ... до ..." -> `BETWEEN`.

## Как читать условие по смыслу
Пример:
```sql
SELECT id, duration_sec
FROM test_runs
WHERE duration_sec BETWEEN 35 AND 60;
```

По смыслу это значит:
- взять таблицу `test_runs`;
- оставить только строки, где `duration_sec` попадает в нужный диапазон;
- показать `id` и `duration_sec`.

## Частые ошибки
- писать `= NULL` вместо `IS NULL`;
- забывать `%` в `LIKE`;
- не помнить, что `BETWEEN` включает обе границы;
- использовать длинный `OR`, когда читаемее `IN`.

## Что проверить перед практикой
Перед `practice.sql` ты должен уверенно различать:
1. отсутствие значения (`NULL`);
2. поиск по шаблону (`LIKE`);
3. поиск в списке (`IN`);
4. поиск по диапазону (`BETWEEN`).
