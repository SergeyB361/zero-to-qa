# NULL, LIKE, IN, BETWEEN

## Когда это нужно
Эти конструкции часто нужны в реальной работе:
- найти пустые поля;
- выбрать строки из списка значений;
- отфильтровать диапазон чисел или дат;
- сделать простой поиск по шаблону.

## Самая важная мысль про NULL
`NULL` - это не пустая строка и не ноль. Это “значение отсутствует”.
Из-за этого с ним нельзя работать как с обычным значением через `=`.
Правильно:
```sql
WHERE closed_at IS NULL
```
Неправильно:
```sql
WHERE closed_at = NULL
```

## Как работают остальные конструкции
`LIKE` нужен для шаблонного поиска по строке.
`IN` удобен, когда допустимых значений несколько.
`BETWEEN` нужен для диапазона, включая границы.

## Как выбирать инструмент
- если ищешь отсутствие значения -> `IS NULL`;
- если ищешь по маске -> `LIKE`;
- если ищешь среди нескольких конкретных вариантов -> `IN`;
- если ищешь диапазон -> `BETWEEN`.

## Пример мышления
Если задача звучит как “найди test_runs длиной от 35 до 60 секунд”, это прямой сигнал к диапазону:
```sql
WHERE duration_sec BETWEEN 35 AND 60
```
Если задача звучит как “найди записи только со статусами open и in_progress”, это сигнал к `IN`.

## Частые ошибки
- писать `= NULL` вместо `IS NULL`;
- забывать `%` в `LIKE`;
- не помнить, что `BETWEEN` включает обе границы;
- использовать длинную цепочку `OR`, когда читаемее `IN`.

## Что проверить перед практикой
Перед практикой ты должен уверенно различать:
- отсутствие значения (`NULL`);
- поиск по шаблону (`LIKE`);
- поиск в списке (`IN`);
- поиск по диапазону (`BETWEEN`).
