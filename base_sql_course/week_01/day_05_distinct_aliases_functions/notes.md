# DISTINCT, aliases, базовые SQL-функции

## Когда это нужно
На этом этапе запросы начинают выглядеть не только рабочими, но и аккуратными.
Эти инструменты нужны, чтобы:
- убрать дубликаты;
- сделать понятные имена колонок в результате;
- сразу выполнить простое преобразование данных внутри SQL.

## Что делает DISTINCT
`DISTINCT` убирает повторяющиеся строки результата по выбранным колонкам.
Это полезно, когда тебя интересуют не сами записи, а набор уникальных значений.

Пример:
```sql
SELECT DISTINCT team FROM users;
```
Здесь нужны не все пользователи, а уникальные команды.

## Что дают aliases
Alias - это новое имя колонки или таблицы внутри запроса.
Это полезно в двух случаях:
1. сделать результат читаемым;
2. сократить длинные имена в сложных запросах.

Пример:
```sql
SELECT name AS user_name, team AS squad FROM users;
```

## Зачем нужны функции
SQL умеет не только хранить данные, но и чуть-чуть их обрабатывать.
Например:
- `COUNT()` считает;
- `LENGTH()` даёт длину строки;
- `UPPER()` переводит текст в верхний регистр.

Это удобно, когда простое преобразование лучше сделать прямо в запросе, а не тащить в Python.

## Частые ошибки
- использовать `DISTINCT`, не понимая, откуда взялись дубликаты;
- давать alias, которые ничего не объясняют;
- забывать, что функции применяются к конкретной колонке или значению.

## Что проверить перед практикой
Ты должен понимать:
- чем `DISTINCT` отличается от обычного `SELECT`;
- зачем нужен `AS`;
- почему иногда проще вызвать `UPPER()` или `LENGTH()` в SQL, чем потом обрабатывать результат в коде.
