# DISTINCT, aliases, базовые SQL-функции

## Зачем это нужно
Это помогает делать запросы чище: убирать дубликаты, давать понятные имена колонкам и использовать встроенные функции без лишней обработки в Python.

## Что нужно понять
- DISTINCT
- AS alias
- COUNT
- UPPER
- LOWER
- LENGTH

## Рабочая логика
1. Определи, из каких таблиц ты читаешь данные.
2. Сузь выборку фильтрами.
3. Только потом добавляй сортировку, группировку или join.
4. Проверяй вывод на маленьком наборе данных.

## Примеры
### Пример 1 - Уникальные команды
```sql
SELECT DISTINCT team FROM users ORDER BY team;
```

### Пример 2 - Переименовать колонки в выводе
```sql
SELECT name AS user_name, team AS squad FROM users ORDER BY id;
```

### Пример 3 - Показать длину заголовка test case
```sql
SELECT title, LENGTH(title) AS title_len FROM test_cases ORDER BY id;
```

## Типичные ошибки
- злоупотреблять `SELECT DISTINCT *`
- давать бессмысленные alias
- не различать SQL-функции и Python-функции
