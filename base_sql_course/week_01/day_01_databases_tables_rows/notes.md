# Базы данных, таблицы, строки и колонки

## Зачем это нужно
Понять базовую модель реляционной БД: где живут данные, чем таблица отличается от базы данных и как строки и колонки превращаются в запрос.

## Что нужно понять
- база данных и таблица
- строка как запись
- колонка как поле
- id как идентификатор
- чтение таблицы целиком и выбор колонок

## Рабочая логика
1. Определи, из каких таблиц ты читаешь данные.
2. Сузь выборку фильтрами.
3. Только потом добавляй сортировку, группировку или join.
4. Проверяй вывод на маленьком наборе данных.

## Примеры
### Пример 1 - Посмотреть список таблиц
```sql
SELECT name FROM sqlite_master WHERE type = 'table' ORDER BY name;
```

### Пример 2 - Прочитать первые строки users
```sql
SELECT id, name, team FROM users ORDER BY id LIMIT 3;
```

### Пример 3 - Посчитать количество проектов
```sql
SELECT COUNT(*) AS project_count FROM projects;
```

## Типичные ошибки
- путать таблицу и всю БД
- не понимать, что одна строка - одна запись
- игнорировать роль `id`

## Практика
В `practice.py` есть функции для самостоятельной реализации:
- `list_table_names` - Верни список имён таблиц, отсортированный по имени.
- `count_users` - Верни количество пользователей в users.
- `list_active_teams` - Верни уникальные команды активных пользователей.
