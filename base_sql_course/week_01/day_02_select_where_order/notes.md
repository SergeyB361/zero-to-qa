# SELECT, WHERE, ORDER BY, LIMIT

## Зачем это нужно
Это минимальный рабочий набор для чтения данных: выбрать колонки, отфильтровать строки, отсортировать результат и ограничить выборку.

## Что нужно понять
- SELECT
- WHERE
- ORDER BY
- LIMIT
- комбинирование условий

## Рабочая логика
1. Определи, из каких таблиц ты читаешь данные.
2. Сузь выборку фильтрами.
3. Только потом добавляй сортировку, группировку или join.
4. Проверяй вывод на маленьком наборе данных.

## Примеры
### Пример 1 - Активные пользователи по имени
```sql
SELECT name, team FROM users WHERE is_active = 1 ORDER BY name;
```

### Пример 2 - Две самые длинные задачи
```sql
SELECT id, status, estimate_hours FROM tasks ORDER BY estimate_hours DESC LIMIT 2;
```

### Пример 3 - Только открытые high priority задачи
```sql
SELECT id, assignee_id FROM tasks WHERE status = 'open' AND priority = 'high';
```

## Типичные ошибки
- путать порядок блоков
- писать строковые значения без кавычек
- сортировать не по тому полю

## Практика
В `practice.py` есть функции для самостоятельной реализации:
- `top_two_open_tasks` - Верни id двух открытых задач с максимальной оценкой.
- `active_web_users` - Верни имена активных пользователей из команды web.
- `projects_sorted` - Верни имена проектов в алфавитном порядке.
