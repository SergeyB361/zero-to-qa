# Финальная практика по SQL

## Зачем нужен отдельный финальный день
Последний практический день нужен, чтобы собрать весь базовый SQL в одну систему. Если темы остались разрозненными, это быстро всплывёт именно здесь.

## Что уже должно быть в голове
К этому моменту ты должен уверенно различать:
- выборку строк;
- изменение данных;
- агрегаты и группировку;
- `JOIN`;
- подзапросы и `EXISTS`;
- схему, ключи и связи;
- set operations, условные выражения и базовую работу с датами.

Если какая-то из этих частей "держится на памяти, но не на понимании", финальная практика это покажет.

## Как правильно проходить этот день
Не решай задачи в режиме перебора. Для каждой задачи полезно сначала зафиксировать:

1. что именно нужно получить;
2. какие таблицы участвуют;
3. нужен ли `JOIN`, подзапрос, агрегат, `EXISTS` или вычисляемое выражение;
4. как должен выглядеть итоговый результат.

## Что считается хорошим результатом
Хороший итог этого дня - не просто рабочие ответы, а способность:
- объяснить, почему запрос написан именно так;
- быстро заметить типовую ошибку;
- выбрать подходящий инструмент без лишней суеты.

## Где это пригодится дальше
После этой точки SQL уже должен стать самостоятельным инструментом для:
- ручного анализа данных;
- чтения и написания pure-SQL запросов;
- перехода к advanced SQL;
- прикладного трека `sql_in_practice_course`.

## Что проверить перед практикой
Перед `practice.sql` ты должен понимать:
1. как выбирать инструмент под задачу;
2. какие темы курса ты уже реально можешь комбинировать;
3. что финальная практика - это проверка целостности твоей SQL-базы, а не просто ещё набор упражнений.
