# CASE, COALESCE, NULLIF

## Зачем это нужно
Эти выражения нужны, когда SQL должен не просто прочитать данные, а аккуратно обработать ветвление, пустые значения и специальные случаи.

## Как об этом думать
- `CASE` — условная логика прямо в запросе.
- `COALESCE` — выбрать первое непустое значение.
- `NULLIF` — превратить одно значение в `NULL`, если оно совпало с заданным условием.
