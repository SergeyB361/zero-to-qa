# CASE, COALESCE, NULLIF

## Когда это нужно
Эти выражения нужны, когда SQL должен не просто прочитать данные, а немного обработать их прямо внутри запроса:
- присвоить категорию по условию;
- подставить значение вместо `NULL`;
- убрать специальное техническое значение и заменить его на `NULL`.

## CASE: условная логика в запросе
`CASE` позволяет написать ветвление прямо в SQL.

Базовый синтаксис:
```sql
CASE
    WHEN condition1 THEN result1
    WHEN condition2 THEN result2
    ELSE default_result
END
```

Пример:
```sql
SELECT title,
       CASE
           WHEN priority IN ('critical', 'high') THEN 'hot'
           ELSE 'normal'
       END AS bucket
FROM tasks;
```

Как это читать:
- если условие выполнено, вернуть одно значение;
- если нет, перейти к следующему `WHEN`;
- если ничего не подошло, взять `ELSE`.

## COALESCE: выбрать первое непустое значение
`COALESCE` проходит по аргументам слева направо и возвращает первое значение, которое не равно `NULL`.

Синтаксис:
```sql
COALESCE(value1, value2, value3)
```

Пример:
```sql
SELECT COALESCE(assignee, 'unassigned') AS assignee_name
FROM tasks;
```

Это значит: если `assignee` заполнен, взять его, иначе подставить `'unassigned'`.

## NULLIF: превратить значение в NULL
`NULLIF(a, b)` возвращает `NULL`, если `a = b`. Если значения не равны, возвращает `a`.

Пример:
```sql
SELECT NULLIF(estimate_hours, 0) AS normalized_estimate
FROM tasks;
```

Это значит: если `estimate_hours` равно `0`, считать это отсутствующим значением и вернуть `NULL`.

## Когда использовать что
- условная категоризация -> `CASE`;
- подставить значение вместо пустого -> `COALESCE`;
- убрать технический маркер вроде `0` или пустой строки -> `NULLIF`.

## Почему это полезно
Эти выражения позволяют сделать запрос более выразительным и сразу подготовить результат в удобном виде. Иначе пришлось бы обрабатывать те же случаи уже после SQL на стороне Python или вручную.

## Частые ошибки
- путать `CASE` и `COALESCE`;
- забывать `ELSE` в `CASE`, когда нужен понятный запасной вариант;
- не понимать, что `COALESCE` возвращает именно первый не-`NULL` аргумент;
- использовать `NULLIF`, не представляя, какие значения действительно нужно считать пустыми.
