# Транзакции: база

## Зачем это нужно
Транзакции нужны, чтобы группа изменений применялась целиком или не применялась вовсе. Это важная база для понимания согласованности данных.

## Что нужно понять
- BEGIN
- COMMIT
- ROLLBACK
- atomicity

## Рабочая логика
1. Определи, из каких таблиц ты читаешь данные.
2. Сузь выборку фильтрами.
3. Только потом добавляй сортировку, группировку или join.
4. Проверяй вывод на маленьком наборе данных.

## Примеры
### Пример 1 - Открыть транзакцию и обновить статус задачи
```sql
BEGIN; UPDATE tasks SET status = 'closed' WHERE id = 3; COMMIT;
```

### Пример 2 - Откатить изменение дефекта
```sql
BEGIN; UPDATE defects SET status = 'closed' WHERE id = 1; ROLLBACK;
```

### Пример 3 - Проверить итоговый статус после rollback
```sql
SELECT status FROM defects WHERE id = 1;
```

## Типичные ошибки
- делать несколько связанных изменений без транзакции
- не понимать разницу между commit и rollback

## Практика
В `practice.py` есть функции для самостоятельной реализации:
- `commit_task_close` - Закрой задачу id = 3 в транзакции и верни итоговый статус.
- `rollback_defect_close` - Попробуй закрыть defect id = 1 и откати. Верни итоговый статус.
- `transactional_insert_and_rollback` - Вставь временного пользователя в транзакции и откати. Верни count строк с этим id.
