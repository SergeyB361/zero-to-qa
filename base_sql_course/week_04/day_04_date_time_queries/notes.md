# Дата и время в SQL

## Зачем это нужно
Без работы с датой и временем невозможно считать активность по дням, строить отчёты по релизам и фильтровать события по интервалам.

## Как об этом думать
Дата и время — это не просто текст. В SQL их нужно уметь нормализовать, сравнивать и группировать по нужным bucket'ам.
