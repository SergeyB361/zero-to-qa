# UNION, UNION ALL, INTERSECT, EXCEPT

## Когда это нужно
Иногда у тебя уже есть две готовые выборки, и задача не в соединении таблиц через `JOIN`, а в работе с результатами как с наборами.

Именно для этого нужны set operations:
- объединить результаты;
- оставить только общие строки;
- найти различия между выборками.

## Как об этом думать
`JOIN` связывает строки из разных таблиц по ключу.

`UNION`, `INTERSECT`, `EXCEPT` работают иначе: они берут два готовых результата `SELECT` и применяют к ним логику операций над множествами.

То есть здесь вопрос не "какие строки связаны", а "как соотносятся два набора результатов".

## Главное техническое правило
Обе части операции должны быть совместимы:
- одинаковое число колонок;
- совместимые типы данных;
- одинаковый смысл колонок по позициям.

Например, корректно:
```sql
SELECT name FROM web_owners
UNION
SELECT name FROM api_owners;
```

## Что делает UNION
`UNION` объединяет два набора и убирает дубликаты.

Пример:
```sql
SELECT name FROM web_owners
UNION
SELECT name FROM api_owners;
```

Если `Anna` встречается в обеих выборках, в результате она останется один раз.

## Что делает UNION ALL
`UNION ALL` тоже объединяет два набора, но не убирает дубликаты.

Пример:
```sql
SELECT name FROM web_owners
UNION ALL
SELECT name FROM api_owners;
```

Если одно и то же имя встретилось несколько раз, оно столько же раз и останется в результате.

Используй `UNION ALL`, когда повторы важны и их не нужно терять.

## Что делает INTERSECT
`INTERSECT` оставляет только те строки, которые встречаются в обоих наборах.

Пример:
```sql
SELECT name FROM web_owners
INTERSECT
SELECT name FROM api_owners;
```

Это полезно, когда нужно найти пересечение двух выборок.

## Что делает EXCEPT
`EXCEPT` оставляет строки из левого запроса, которых нет в правом.

Пример:
```sql
SELECT name FROM web_owners
EXCEPT
SELECT name FROM api_owners;
```

Это полезно, когда нужно найти различие между наборами.

## Как выбирать нужную операцию
- объединить уникальные результаты -> `UNION`;
- объединить всё, включая повторы -> `UNION ALL`;
- оставить только общие строки -> `INTERSECT`;
- оставить только строки слева без совпадений справа -> `EXCEPT`.

## Как проверять результат
Сначала зафиксируй, что возвращает каждый `SELECT` по отдельности. Потом применяй set operation и проверяй, соответствует ли итог логике объединения, пересечения или разницы.

## Частые ошибки
- использовать операции над наборами там, где нужен `JOIN`;
- забывать, что `UNION` убирает дубликаты;
- ожидать, что `EXCEPT` работает симметрично в обе стороны;
- соединять выборки с несовместимыми колонками.
