# UNION, UNION ALL, INTERSECT, EXCEPT

## Зачем это нужно
Иногда данные уже собраны двумя или тремя отдельными запросами, и задача состоит не в `JOIN`, а в объединении или сравнении готовых выборок.

## Как об этом думать
Set operations работают не по принципу связи строк между таблицами, а по принципу работы с наборами результатов.
- `UNION` объединяет два набора и убирает дубликаты.
- `UNION ALL` объединяет два набора и оставляет дубликаты.
- `INTERSECT` оставляет только общие строки.
- `EXCEPT` оставляет строки, которые есть слева, но отсутствуют справа.
