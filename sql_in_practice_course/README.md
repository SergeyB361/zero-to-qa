# Курс: SQL in Practice

Прикладной SQL-трек про использование SQL в Python, тестах, инженерных сценариях и расследовании проблем.

## Зачем нужен курс
- научиться применять SQL не только как язык запросов, но и как рабочий инструмент в коде и тестах;
- строить DB-checks, подготавливать данные и разбирать инциденты;
- понять инженерные workflow вокруг SQLite и query-driven расследований.

## Формат
- `1` основная неделя
- `1` bonus-модуль
- обычный день: `notes.md`, `examples.py`, `practice.py`
- мини-проектный день: `notes.md`, `spec.md`, основной `.py`

## Структура курса
- `week_01/` — SQL в Python и тестах
- `bonus_backend_api_analysis/` — bonus: SQL для backend и API-анализа
