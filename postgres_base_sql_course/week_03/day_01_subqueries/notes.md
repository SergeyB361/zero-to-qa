# Подзапросы

## Когда это нужно
Подзапрос нужен, когда часть ответа сначала надо вычислить отдельным запросом, а потом использовать внутри внешнего запроса.

Типовые случаи:
- сравнить значение со средним по таблице;
- проверить попадание в набор id;
- взять данные только для строк, связанных с результатом другого запроса.

## Как об этом думать
Подзапрос — это не «магия внутри скобок», а нормальное разбиение задачи на два шага.

Например:
1. сначала найти среднее `estimate_points`;
2. потом выбрать только те задачи, которые выше этого среднего.

Если держать в голове эту последовательность, запрос легче читать и писать.

## Базовые типы подзапросов
На этом уровне достаточно понимать два варианта:
- подзапрос возвращает одно значение;
- подзапрос возвращает набор значений.

Первый часто используется с `=`, `>`, `<`.
Второй — с `IN`.

## Пример с одним значением
```sql
SELECT id, estimate_points
FROM tasks
WHERE estimate_points > (
    SELECT AVG(estimate_points)
    FROM tasks
);
```

Смысл:
- внутренний запрос считает среднее;
- внешний сравнивает каждую строку с этим средним.

## Пример со списком значений
```sql
SELECT name
FROM users
WHERE id IN (
    SELECT owner_id
    FROM projects
);
```

Смысл:
- внутренний запрос получает список `owner_id`;
- внешний оставляет только пользователей, чей `id` есть в этом наборе.

## Когда подзапрос лучше, чем JOIN
Если задача — просто сравнить значение с итогом другой выборки или проверить попадание в набор, подзапрос часто читается проще, чем `JOIN`.

Но подзапрос — не универсальная замена `JOIN`. Это просто другой инструмент.

## Частые ошибки
- не понимать, что возвращает внутренний запрос: одно значение или много;
- использовать `=` там, где подзапрос возвращает несколько строк;
- писать подзапрос, когда обычный `JOIN` был бы проще;
- читать запрос только как синтаксис, а не как последовательность шагов.

## Что нужно понимать перед практикой
Перед `practice.sql` ты должен понимать:
1. зачем нужен подзапрос как отдельный шаг вычисления;
2. чем подзапрос с одним значением отличается от подзапроса со списком;
3. как по смыслу выполняется `WHERE id IN (SELECT ...)`.
