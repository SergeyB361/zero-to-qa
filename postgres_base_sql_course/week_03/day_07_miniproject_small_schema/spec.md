# ТЗ: Мини-проект — small schema

## Цель
Создать небольшую Postgres-схему, наполнить её тестовыми данными и выполнить несколько проверочных запросов.

## Deliverables
- блок `create_schema`
- блок `seed_data`
- запрос `list_tables`
- запрос `query_overview`
- demo flow в `small_schema.sql`

## MVP-идея
Сделай маленькую схему из трёх таблиц, например:
- `teams`
- `services`
- `incidents`

Или выбери свою близкую по смыслу тройку сущностей.

## Обязательные требования
- используй identity columns;
- добавь минимум один `FOREIGN KEY`;
- добавь минимум один `CHECK` или `UNIQUE`;
- добавь seed-данные;
- добавь хотя бы один рабочий `JOIN`-запрос по своей схеме.

## Пример допустимого вывода
```text
Tables: incidents, services, teams
Overview rows: 3
```

## Критерии готовности
- SQL-скрипт выполняется без ошибок на Postgres;
- схема читается и имеет понятные ограничения;
- seed-данные соответствуют схеме;
- `small_schema.sql` показывает рабочий demo flow.
