# Мини-проект: dataset queries

## Зачем нужен этот день
До этого неделя шла как набор отдельных тем. В мини-проекте нужно показать, что ты умеешь собрать несколько самостоятельных запросов к одному dataset и оформить это как понятный SQL-артефакт.

## Что считается сильным результатом
Сильный результат здесь — не «очень сложный SQL», а:
- запросы без лишнего шума;
- читаемые имена блоков;
- понятная логика фильтрации и сортировки;
- результат, который можно показать другому человеку без устного объяснения на полчаса.

## Как работать
1. Прочитать `spec.md`.
2. Выписать каждую задачу обычным языком.
3. Для каждой задачи выбрать таблицу и нужные колонки.
4. Собрать запрос.
5. Добавить короткий demo flow в `dataset_queries.sql`.

## На что не надо тратить время
- не нужно усложнять проект `JOIN`, если задача решается одной таблицей;
- не нужно писать «умный» SQL ради сложности;
- не нужно смешивать в одном запросе несколько разных бизнес-вопросов.

## Что должно получиться
Итогом должен стать SQL-файл, который можно открыть в `psql` или `DBeaver`, выполнить и сразу увидеть полезный набор базовых выборок по QA dataset.
