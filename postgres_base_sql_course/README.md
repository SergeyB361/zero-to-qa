# Postgres SQL — базовый курс

**Цель:** Собрать фундамент по чистому SQL уже на реальном Postgres runtime.
**Длительность:** `4 недели`
**Статус:** Scaffold новой Postgres-native версии. Старые SQLite-курсы оставлены в репозитории как history/legacy.

## Общее правило
- Используй общее окружение из `postgres_lab/`.
- Старые `base_sql_course/`, `advanced_sql_course/` и `sql_in_practice_course/` остаются в репозитории как historical reference.

## Недели
- `week_01/` — Базовые запросы и изменения данных
- `week_02/` — Агрегации и JOIN
- `week_03/` — Подзапросы и схема данных
- `week_04/` — Postgres-native SQL: закрепление
