# ORM Review Practice

## Зачем этот день
Это контрольная сборка всего блока:
- модель;
- связь;
- select;
- session lifecycle;
- структура кода.

## Что отличает сильное решение
- нет hardcoded ответа вместо реального чтения из БД;
- один сценарий = один понятный session scope;
- ORM-код читается как слой данных, а не как набор случайных side effects.
