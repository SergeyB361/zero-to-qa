# ORM Basics Practice

## Зачем этот день
После engine, models, CRUD, relationships и select-patterns важно собрать всё в одну картину. Без этого ORM остаётся набором разрозненных API-вызовов.

## На что смотреть
В этой практике важны не только правильные методы SQLAlchemy, но и порядок действий:
1. reset schema;
2. создать связанные данные;
3. сделать чтение через select;
4. вернуть удобный Python-результат.

## Критерий хорошего решения
- нет лишней ручной магии;
- данные действительно сохраняются и читаются из БД;
- ответ из `run_flow()` отражает результат сценария, а не hardcoded словарь.
