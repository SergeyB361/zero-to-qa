# Мини-проект — Library ORM

## Задача
Собрать небольшой ORM-модуль для каталога библиотеки:
- авторы;
- книги;
- связь автора и книг;
- базовые операции чтения и создания.

## Что здесь важно
Это уже не отдельная техника, а маленький модуль данных. Здесь проверяется, насколько ты умеешь:
- проектировать модели;
- строить relationship;
- писать читаемые CRUD-функции;
- держать Session под контролем.

## Критерий хорошего решения
- модели отражают нормальную схему, а не хаотичный набор полей;
- create/read операции действительно работают через ORM;
- smoke-check проходит без ручных подмен.
