# Select, Filters, Ordering

## Когда это нужно
ORM полезен ровно до тех пор, пока ты понимаешь, какой SQL он порождает. Поэтому важно работать через современный `select(...)`, а не через магические цепочки без понимания результата.

## Как об этом думать
`select(Model)` — это объект запроса.
Дальше ты уточняешь его через:
- `.where(...)`;
- `.order_by(...)`;
- иногда `.limit(...)`.

Потом этот запрос исполняется через `session.execute(...)`.

## Что важно понять
- ORM querying — это всё ещё querying, а не просто Python-списки;
- сортировка и фильтрация должны оставаться в БД, а не переноситься в Python без причины;
- `scalar_one`, `scalars().all()`, `first()` различаются по контракту.
